# Pareto Decisiones

Herramientas educativas interactivas basadas en el **Principio de Pareto (80/20)**.

## Estructura

```
Pareto-decisiones/
├── index.html          ← Portada principal del sitio
├── assets/
│   ├── style.css       ← Estilos globales
│   └── script.js       ← Scripts del index
└── pages/
    └── infecciones.html  ← Análisis de infecciones hospitalarias
```

## Herramientas disponibles

- **Infecciones Hospitalarias** — Análisis de Pareto para causas de infecciones nosocomiales. Incluye escenarios de UCI, lavado de manos, neonatología y constructor de escenarios propio.
